# PO Personal Brand Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/po/` — a PO-focused personal brand site with portfolio page, infographic PDF resume, and 4 case detail pages, all using the approved bold gradient design.

**Architecture:** Pure HTML/CSS/JS — no build tools, no frameworks. Each file is fully self-contained with inline styles and scripts. Design tokens shared via CSS custom properties defined in each file's `<style>`. Deployed via GitHub Pages (push to `main`).

**Tech Stack:** HTML5 · CSS custom properties · Vanilla JS (ES2020+) · Pretendard (Google Fonts CDN) · html2pdf.js 0.10.1 (CDN, resume only)

**Visual reference:** Approved mockup at `.superpowers/brainstorm/*/content/full-mockup.html`
