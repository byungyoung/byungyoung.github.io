CASE 01 · XITST

비접촉 감정 분석으로
정확도 92% 달성

카메라만으로 심리 상태를 측정한다. 접촉식 장비 없이 임상 수준의 정확도를 만들어낸 과정.

92% 감정 탐지 정확도
전통 접촉식 장비 대비
Context

문제: 심리 치료의 접근성

전통적인 심리 상태 측정은 전극·센서 등 접촉식 장비가 필요해 병원 방문이 필수였습니다. Xitst는 비대면으로 심리 상태를 분석하고 맞춤형 치유를 제공하는 플랫폼을 목표로 했고, 핵심 기술 문제는 "카메라만으로 신뢰할 수 있는 생체 신호를 추출할 수 있는가"였습니다.

CTO로서 제품 로드맵 설계와 함께 rPPG(Remote Photoplethysmography) 기술의 실현 가능성을 검증하고 임상 적용 수준까지 끌어올리는 것이 제 역할이었습니다.

Process

접근 방식

  • 신호 처리 파이프라인 설계: 얼굴 영상에서 미세한 혈류 변화를 감지하는 rPPG 알고리즘 구현. 조명·움직임에 따른 노이즈를 필터링하는 신호 처리 파이프라인을 단계별로 구축.
  • TCI 심리 모델 통합: 원시 생체 신호를 TCI(기질 및 성격 검사) 모델과 결합해 감정 상태로 변환하는 데이터 통합 시스템 개발.
  • 클라우드 아키텍처: 실시간 처리를 위해 AWS Lambda + API Gateway 서버리스 구조 채택. Next.js SSR로 프론트엔드 응답 속도 최적화.
  • 반복 검증: 내부 테스트 → 외부 피험자 실험 → 정확도 측정의 사이클을 반복해 92% 달성.
Result

결과

  • 전통 접촉식 방법 대비 92% 감정 탐지 정확도 달성
  • 실시간 생체 데이터 + 심리 프로필 통합 치료용 채팅 서비스 출시
  • 확장 가능한 서버리스 인프라로 동시 사용자 처리 비용 절감
Learned

배운 것

기술 로드맵의 현실화

연구 수준의 알고리즘을 프로덕션에 적용할 때 정확도와 실시간성 사이의 트레이드오프를 명확히 정의해야 한다.

의료 도메인의 검증 기준

임상 적용을 목표로 할 때는 사용자 테스트 기준이 일반 앱과 다르다. 피험자 프로토콜과 IRB 관련 프로세스를 미리 설계해야 한다.

데이터 파이프라인 우선

AI 기반 제품에서 모델보다 데이터 수집·정제 파이프라인이 먼저다. 초기에 데이터 품질 기준을 높게 잡을수록 이후 반복 속도가 빨라진다.
